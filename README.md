# Brainrot Clicker — descargas

Acá se publican las versiones de Brainrot Clicker para Android.

## Instalar

1. Desde el celular, abrí la [última versión](https://github.com/tukpot/brainrot-clicker-releases/releases/latest)
   y bajá el archivo `.apk`.
2. Abrilo. Android te va a pedir permiso para instalar apps desde el navegador: activalo.
3. Listo. Las próximas versiones se instalan desde el mismo juego: cuando hay una nueva, te avisa al abrirlo.
